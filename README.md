# Genbytez Connect

Build a complete, premium, production-quality corporate website for Genbytez, an IoT & Digital Solutions company based in Chennai, India.

Use https://toolfe.com/ as a reference for the quality, structure, visual hierarchy, animation style, and conversion-focused approach.

IMPORTANT:

Do NOT clone Toolfe.

Do NOT copy Toolfe's text, images, illustrations, branding, logo, colors, or exact layouts.

Create an original visual identity for Genbytez.

The website should feel like a premium global technology company.

Genbytez should be positioned primarily as an IoT and Digital Solutions company, not as a generic software outsourcing company.
